What is HTF?

Hack The Flag is a cryptography competition. You connect, you get a cipher, you break it. The output is a flag — submit it, earn points, climb the leaderboard.

No prior experience required. Every cipher is solvable. The only question is how fast.

How it works

  1. 01
    Connect

    SSH into the competition server when the event goes live.

    ssh app.hacktheflag.net
  2. 02
    Solve

    Pick a cipher challenge. Break it — classical, modern, steganography, whatever it takes.

  3. 03
    Capture

    Every solved cipher reveals a flag. Submit it.

    <HTF-your_flag_here/>
  4. 04
    Repeat

    More flags, more points. The leaderboard updates live.
